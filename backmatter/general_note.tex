\chaptermark{About the Arliz Project}

Arliz is an open-source work. The complete source every chapter, figure,
and build script is available at \url{https://github.com/papyrxis/arliz}
under a dual license: book content under CC~BY-SA~4.0, code and tooling
under the MIT License.

If something in this volume is wrong, unclear, or incomplete, an issue or
pull request on the repository is more useful than silence. The work
improves through the people who read it carefully enough to notice what
is missing.
