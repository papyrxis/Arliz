Preface

From a Simple Question
to a Started Everything

ARLIZ began with one uncomfortable question: what is an array, really? Following it seriously turned a familiar programming topic into a much larger inquiry about memory, logic, abstraction, and computation itself.

ARLIZ was not conceived as a broad survey of computer science. It emerged from a narrower impulse: to revisit one of the oldest structures in programming with enough honesty to admit that the usual answers were incomplete — and to follow the question all the way from a voltage difference to a tensor.

"To understand arrays seriously is to move from notation to mechanism — from symbols in code to the hardware and logic that make those symbols real."

That path is long enough that it no longer fits in a single book. ARLIZ is now organized as three volumes — Zero to Bit, Silicon Horizon, and Array Odyssey — each a complete stage of the same journey, readable on its own but part of one continuous line of reasoning. See Volumes below for how they fit together.

It is also a living work: errors get corrected and explanations get sharper, and each volume keeps improving on its own schedule.

The Work

One Journey, Three Volumes

ARLIZ follows a single path — from a voltage difference to a tensor — divided into three volumes that can each be read, revised, and downloaded on their own.

Volume I

Zero to Bit

How information is encoded at all — voltage and binary switching, Boolean algebra, number systems, integers, floating point, characters, endianness, bit manipulation, alignment, and serialization.

Read PDF →
Volume II

Silicon Horizon

The hardware that turns encoded information into computation — logic gates, memory cells and hierarchies, processors, pipelines, ISAs, SIMD, GPUs, and interconnects.

In progress
Volume III

Array Odyssey

Arrays themselves, in full — theory, memory layout, every major variant, the data structures and algorithms built on them, and the parallel and distributed systems that process them today.
